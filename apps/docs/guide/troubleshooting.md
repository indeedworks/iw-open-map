# 地图不显示排查

1. **容器没有高度**：地图容器必须有明确高度，例如 `height: 500px`。
2. **Key 未配置或类型不对**：确认申请的是天地图浏览器端 Key，环境变量已重启生效。
3. **域名白名单不匹配**：本地开发通常需要允许 `localhost`；生产环境填写实际域名。
4. **请求被拦截**：在浏览器开发者工具 Network 中检查 `tianditu.gov.cn` 请求及状态码。
5. **坐标顺序错误**：OpenMap 使用 `[经度, 纬度]`，北京约为 `[116.397, 39.908]`。
6. **CSS 未引入**：npm 项目应引入 `@indeedworks/open-map/style.css`。
7. **页面从 HTTP 嵌入 HTTPS 限制资源**：生产环境应统一使用 HTTPS。

请勿为解决跨域问题而搭建批量瓦片代理、缓存或下载服务。不得移除地图上的版权、数据来源与审图信息。
